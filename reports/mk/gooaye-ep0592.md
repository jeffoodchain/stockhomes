## NVIDIA Rubin CPX 不是取代 HBM

那稍微待會聊一下，現在在市場上的一些話題。那首先呢，因為我們在上集只有跟大家快速地更新輝達的新的 CPX，這個 GPU 到底是在做什麼，那在講完之後呢，就這個禮拜開始就有出一些新聞，那有些新聞我認為他們是寫錯的。這邊就稍微來跟大家分享一下自己的一個意見。

就是有新聞是提到說 CPX 會導致 HBM 的用量減少，為什麼？因為它用 GDDR 嘛，所以就認為說，那既然現在開始有 GPU 用 GDDR 的話，那是不是就會排擠掉一些在使用 HBM 的 GPU 呢？其實不是這樣子的一個狀況，因為如果說上集大家要仔細聽的話，就會知道說其實這個 CPX 呢，是額外在一個伺服器的 tray 裡面去加的。那一個 tray 裡面大概是多 8 顆嘛，所以它是外加的東西啊。

也就是說，本來是沒有這個東西，額外加進來，它並沒有說把 Vera Rubin 的那個 Rubin 的 HBM 的 setting 給改掉，它是額外加的東西。所以你只能夠視為說是額外多了一些需求。那也因為它並沒有去使用 HBM，所以呢它不會用到 CoWoS，那它的封裝方式也會是不太一樣的。

所以如果在之後要去推 NVIDIA 的一個數字，以前很多人會用 CoWoS 的數量去推，那是因為說它的晶片都是用 CoWoS，絕大多數。那現在不用 CoWoS 的東西是越來越多了，所以會變成未來你要用 CoWoS 去推說 NVIDIA 的營收的話，就變得相對的困難。

那這邊稍微簡單地跟大家示意一下，就是這個市場上面出現的一些新聞是假的，就是說什麼這個東西會排擠掉那個東西的需求，不是，它並不是一個取代的概念，這個還蠻重要的。

那畢竟大家應該知道說，就是我們去講這個記憶體的風潮，其實從去年講到現在，這個不是要去講說是自己多早以前講，我意思是說，你看就去年講的時候其實是沒有反應的嘛，然後今年才反應。所以我們會說，其實你要去 call 那個時間是很困難的。那我們能夠做的事情是什麼？就是你每次覺得好像有一點味道的時候，你就先上去，然後你發現他沒有動的時候，你就把他砍掉。

其實我們做交易真的就是這樣，包含說像我自己去跟 A 君講也是這樣講。就是不管你自己買單的故事是你覺得他有多好，或是多屌，但如果這時候市場沒有去動他的話，其實你最終是要跟市場對打，因為你要賺的是價差。那如果沒有人要去動他，你就沒有價差，所以怎麼辦？你就先退出先休息。

除非說你的錢很多，那你就放著等，那可能可以。那如果說錢少，至少要去追求效率的話，很多時候這個故事可能是一直存在，那只是有時候就是他沒有等到他的東風，然後他的東風一來的時候，你只要趕快跳上去就好。

那即便有時候可能看起來是偏高，這個也是我覺得為什麼有些人交易沒有辦法做得好的原因，是因為東風來了，然後他一吹上去，他可能直接先噴個 12%，連續兩根漲停上去之類的，然後他就不敢買了，他就覺得說他要等拉回，然後就一輩子等不到拉回，然後真的拉回的時候就是出貨的時候。所以敢去追高，我覺得也是要把交易做好蠻重要的一個關鍵。

當然我知道很多人對這個認知是不一樣的，然後甚至連我自己，在不同的部位的做法也都不一樣。有些東西我覺得可以追高，特別是那種很動能的東西，一些漲報價的題材，那個一定都是要追高的。可是有些東西如果不是這樣子，那可能不一定會追高，反而會用低接，所以很多時候要去拿捏這些東西，我覺得沒有這麼簡單，所以就大家大概聽一下，氣氛一下就好。

那這個禮拜，記憶體就開始出了很多的訊息，包含像是美光是直接公佈說他們要暫停 NAND 報價一個禮拜。那這個東西，我覺得就是上個禮拜我們跟大家分享說市場上是不是有些人買錯東西，明明就是 SanDisk 它要出現一個漲價的狀態，應該大家要去買 NAND 才對吧，就怎麼會這麼多人跑去買 DRAM？

可是那時候我們在節目不是講說，就是以前的自己就會覺得說這些人是他媽白痴，可是現在就會知道說，因為有太多這種先知，春江水暖鴨先知，他都是先知道一些狀況，也不是說什麼每個人都是內線交易，不是每個人都知道說美光一定會在這個時候去停止報價，但是很多時候真的就是你感覺氣氛對了，你就去買一個東西，可能是因為線型好或什麼的，然後這邊給你賽道，就正式往那個方向。

所以為什麼我們就判斷一些技術線型，是因為技術線型是一個很直覺的東西，基本上就是你在市場上面的買賣的軌跡，就會顯示在你的 K 棒裡面。誰會沒事把東西往上買？當然有時候可能是買錯，那有一定的機率是什麼買錯，然後可能是什麼非常值或什麼的，可是一般來說，我們不會因為說它有一定的機率是假的，我們就放棄它，就所有的訊號我們都還是會盯著它看。

那很快的，就是我們看到這個美光的暫停報價。那除此之外，在台灣的某 NAND Controller 的公司，也傳出說他們在暫停報價，但這個可能就沒有見報，這個是我們自己在我們的訊息管道裡面考察到的。

所以其實我覺得這個記憶體公司，很多時候，以前我會用比較難聽的話，但我不是惡意，我就說上下交相賊，然後說大家是怎樣，是講好的嗎？突然間什麼哪一個記憶體廠淹水，有颱風什麼，然後大家就停止報價，然後就一起漲價。即便外面可能沒有說供需失衡，但大家就是好像說不知道，G 點漲在什麼臉上之類的，稍微摸一下，哇靠，就趕快有很大的一個反應，然後去做出一些，就感覺像要炒股票的感覺。

可是實際上，因為這個就是記憶體廠的一個現狀，不管是 DRAM 或是 NAND，我們很多時候都會看到這樣的一個情形。

所以我會認為說，以這一波來看，因為我們前面其實只有注意到說 NAND 的報價有稍微的上升，就是在一個預期上面，我們是有這樣子的一個判斷的可信度，就是我們覺得說應該是會往這個方向去走，但是應該是不至於到就是好像是瞬間緊缺，然後必須要去做停止報價。

所以我認為說，現在這一段就大家看到這個停止報價，有點像是說這些記憶體商他們自己也聞到有味道，所以他們就提早先去做出這樣的一個處理，但實際上我們目前看到的缺口應該會落在從第四季開始才會加速，到明年一二季的時候才會比較明顯。

所以其實跟那個銅箔基板裡面那個銅箔，那個銅箔也是大概在明年一二季的時候，會逐季去放大那個缺口。所以缺口在那邊，那當然這個股價，像銅箔就已經提早就先動了，那像記憶體就是比較慢動，可是都是提早會去動，然後等到可能真的缺口到的時候，就不一定這股價就動了，有可能就已經反應完了，所以我們再看一下後續的一個狀況。

那目前我們在市場上知道說會比較缺的東西，就 DRAM 是確實會很缺，因為 HBM 的需求還是非常的大，然後再加上新增，就是說 NAND 的需求應該也蠻不錯的，特別是在企業級 SSD 的部分，QLC SSD 應該會是市場上最缺的東西，因為開始有蠻多人去把各大 CSP 他要的 SSD 的數量，這些企業級 SSD 的數量把它加起來之後，然後發現說是嚴重的供不應求，他們要的那個儲存的空間是很大的，可是實際上面市場上的缺口可能已經高達一兩成以上。

那再來就是因為 HDD 目前在市場上面是一個非常緊俏的狀態，所以蠻多東西可能就只好轉向 SSD，所以也會導致 SSD 的缺口持續放大。那這應該是在接下來的兩個 Q 左右會看到。那一樣這個股價蠻多時候會先動，然後特別是，你看這些記憶體廠，他們只要發現氣氛對了，他們就立刻什麼停止報價，他們就希望去拱價格，所以有可能會注意到這波反應會蠻快的，就是會一波反應到位，然後等到可能真的缺的時候就不一定會漲，有可能會是這樣的狀況。

那也有可能就是真的像 Morgan Stanley 的報告，或是一些現在開始有研究分析報告持續地跑出來，就是說這會是一個 NAND 的大潮，那這我們要再稍微觀察一下。這個東西我覺得沒有人有本事，或是有把握在一開始就直接去扣，因為說哪些人有扣到，那可能是他賽到，很多時候我們在市場裡面還是要謹記，就是絕大多數的時間，我們是要見招拆招。那即便可能會因此增加一些摩擦成本，但這是保護自己的一個好辦法。

就如果說你每次都相信說，你知道我們從 2018 年以來，因為那時候有一個國巨，所以一堆人就是整天看到什麼東西都說國巨 2.0，然後現在可能有些東西真的給他們 call 到，就是國巨 2.0。可是過去每個喊國巨 2.0 的，很多可能最後面都套死在山上。我意思就是說，一些大潮的形成有時候它不只是，怎麼講，就是說簡單的一個供需的變化，是要有天時地利人和，又遇到一些什麼天災，然後或者就遇到一些哪個大公司突然決定要停產或什麼的，是要有蠻多事情疊加起來才會變成那種超級恐怖的一個大破斷。

那這個蠻多時候呢，我們沒有必要在一開始就想要去當一個預言家去扣它，因為這沒有意義。我們只要是抓到一個契機，然後接著呢，之後在過程之中持續地去更新它，只要在裡面都有賺到就好。就是不用說什麼期待什麼每個東西要從魚頭抱到魚尾，那個是一個比較不切實際的做法。然後如果你整天都有這樣子的想法的話，你也很高機率那些東西你就套在山頂。

所以每個東西都要有話，這邊要稍微地提醒一下。那接著我們就來觀察一下這個 NAND 跟 DRAM，到底這一波可以發酵的多遠。我覺得下個禮拜就可以得到一些解方。那現階段來看是整體都非常的強勢，那一些這種 NAND 的廠商，像是鎧俠（Kioxia）、美光、威騰、海力士，其實那個股價都是全部都已經漲到右上角去了。或是像今天跟大家聊到的一些硬碟廠，然後或者是一些儲存的 Server 廠，其實目前的表現都是極好。所以看得出來是整個市場的族群已經是走出來了，然後台灣的有些東西是開始進入一個落後補漲的階段，那我們再看他們會怎麼樣去做發展。

## 國巨非合意收購茂達

那接下來我們就來聊一下，國巨要去收購茂達的事件。預計是要收購 5 到 20 幾趴的一個股份，那收購的價格是大概在 230 塊左右，也就是應該是可以期待下個禮拜就會直接拉到 230 幾塊，除非茂達有發出什麼樣的宣告，他是要反擊，還是他要去引入一個白馬騎士來救他之類的，就類似像芝浦那樣子。

芝浦他可能不是很想要給國巨吃，所以他就找了一個幫手來，這個幫手進來就出價，國巨如果要吃到的話，他就只好一直加價，所以對於芝浦來講就直接拉到反向，當然芝浦現在應該是看得出來，日本來救駕的物件是不夠的，所以國巨應該是會成功。在茂達這邊就要觀察一下公司會怎麼樣去做反應。

那我們先快速地介紹一下兩家公司。那國巨應該大家非常熟悉，反正就是被動元件大廠，世界大廠，頂尖的大廠，然後他還一直去做橫向的併購，所以基本上現在就是一方之霸。那同時呢，他其實在 PMIC 的佈局這不是第一次，前面有富鼎，然後再來有力智，然後現在又要去收茂達。

所以就像朋友跟我開玩笑講的，就是說未來 NB 廠可能溢價非常困難，因為 PMIC 廠都是同一個老闆。然後現在又不能夠跟某些日系廠買，因為可能是偏中系的，所以如果你要買台系的話，他都同一個老闆，所以未來價格可能就綁得比較實一點。

那為什麼他要這樣子做呢？當然有很多原因，也有可能就像他自己講的，這個純財務的規劃，只是我們都知道說，事情一般來說不會是這麼單純，他應該是有一些比較長遠的佈局。我個人認為是有點類似說，像 Delta 下面有乾坤，在做這個被動元件電感相關，非常強大的一個公司。那目前國巨自己本身有做被動元件，可是他們可能注意到說，DC to DC 的這個 Delta Center，在電感上面，有 TVLR 電感這種東西，然後可能是要搭配說，他今天有 Power 晶片廠，他就是這種主動晶片廠的話，他本來可能是賣零元件、被動元件，可能是各論各在賣，然後現在是賣模組，那模組價格可能就可以開的比較高一點。

所以他打的算盤應該是他要去切，不管是這個 Server 或是其他一些那種立機型的應用，價格比較高的，當今天可以把它變成是從元件升級成為模組的話，其實整體對公司的發展來說都會是一個更好的方向。

那對於茂達本身來說的話，我就比較中性一點，就是他可能生意還是繼續做這樣，那只是在國巨這邊的話呢，那他就可以把他的一些被動元件放進去一起賣，那其實以整個國巨企業來講，我覺得會是一個蠻不錯的方向。

那茂達這家公司，我們過去也是蠻頻繁地跟大家聊到，因為過去有幾個題材，然後不然像我自己有在交易，所以就會拿出來跟大家提。像那時候是任天堂，任天堂的話就是他有在做那個 Fan Control IC，然後再來就是在 DDR5 的階段的時候，因為那時候大家有在做那個 AIPC，後來 AIPC 這個題材是沒有做起來，所以應該蠻多資金都撤了。

那時候在做這個 AIPC 的時候，也有蠻多人會去交易 DDR5 相關的一個故事，那 DDR5 裡面現在都會使用 PMIC，然後跟這個 CKD RCD 的 chip，所以就變成說，像茂達就變成是在這個核心裡面一個重要的公司，然後他們也有佈局進去，像是 Server Fan 這種東西，所以持續上都是有蠻多新的題材的開出。

那只是過往它的那個股價是屬於比較牛皮的，就這家公司，它的營收獲利狀況都很好，可是它股價就是比較不會動。那沒有辦法，就是有些公司都是這樣的一個樣態，可能是因為公司比較保守，他們比較不會在法說會，或是一些對外的說明會上，就是你知道吹得那種飛天遁地，所以很多股價很活潑其實是因為他們很會跟市場溝通。

還有些公司可能就是比較不會跟市場溝通，比較就是像是說，我好好地把自己事情做，所以就顯示出他的那個股價就相對的牛皮一點，但其實是一個非常穩健又強大的公司。

那陳泰銘這個投資呢，其實我覺得有可能他想的是一石二鳥，因為他進去，你看起來是他吃下茂達嘛，可是同時因為茂達持有了四十幾趴的大中，就是他下面做 MOSFET 的一個子公司，所以等於說在 MOSFET 這邊，他又額外地在擴下一個版圖。

所以我覺得這個交易其實是極爽的，因為茂達的股價就像我剛剛前面講，他是比較牛皮一點，所以我不認為他會買貴，他不只買便宜，然後他一次收到兩家公司的意思。那茂達還有一個特色是什麼？就是他的董監持股是很低的，所以其實這一筆如果進來買的話，不用說我自己先大膽猜測，就是他們應該會反抗吧，應該會試著去可能去搶股票，或者是不知道什麼毒藥丸，還說怎麼找白馬之類的。

因為這個買下去的話，你自己本身的董監持股這麼低，等於公司是直接遜掉，就等於就被他買走了，但不是一個什麼純財務規劃，他只要可以買到那個量的話，不用買到一半都不到，他可能就已經有公司的一個實質控制權了。

所以我個人是還蠻好奇後續會怎麼樣的一個發展，然後就是等到目前都沒有看到他有什麼回應，我覺得是蠻特別的，就是公司都還在一個相對靜默的狀態，然後在下個禮拜就會直接到他目標的一個收購價，那時候我們就來觀察一下市場上的張數，如果說他是一次就有收到那個量的話，那就等於說他已經打贏了，他直接去控制了這家公司。

只是在接下來，因為還有一兩天的時間，我們就來觀察一下茂達會有什麼樣的一個，不知道，就是搞不好他們不想要被收之類的，他們去找一些白馬來救駕之類的，這個是我們可以期待的一件事情，就等於說我們當戲看。像那時候芝浦要被熱熱鬧鬧地買的時候，也是找了鴻海來救他，所以到時候會怎麼樣發展，這個我們就持續的觀察下去。

但稍微評價這個事件，就覺得說這個交易買得非常好，那當然等於是間接捧自己，因為我很喜歡茂達這家公司，我跟陳泰銘想的一樣，我覺得這家公司超棒，只是市場不喜歡他。那像有這個懂得欣賞他的人要直接把他給買下來，那我覺得是非常讚的事情。

然後再來就是買下來之後，我覺得他去切蠻多市場都會變得更加順利，那外加他可以把他從本來是賣元件，然後變成是賣模組，所以價格又會變得更好，整個集團的滲透又變得更加強大，其實整體看起來是一個非常棒的收購，就一如既往，就是他真的很會買東西。
