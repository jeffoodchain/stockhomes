## 開場 / 贊助：NordVPN

歡迎收聽股癌，我是謝孟恭，本集節目由 NordVPN 贊助。4 月到了，大家是不是都準備好安排春遊或規劃接下來的長假呢？不過最近國際局勢動盪不安，例如中東地區的緊張情勢讓機票價格貴得卻步，旅遊預算很難控制。

## 近況：瘦瘦針心得與打網球

上集跟大家分享了自己打瘦瘦針的心得，現在已到後半段，準備要打第二針。對我來說，胃口反而是變大了，每天只要到吃飯時間就超期待吃飯，好像突然覺得飯很好吃，有點像以前國中上完體育課要吃便當的那種感覺。食量還是有稍微縮減一點，體重是直線斜斜的穩定下滑，整體來說還蠻不錯的。

書桌隔壁擺了一整袋兩個禮拜前跑去 7-11 買的甜食——七七乳加、健達巧克力、硬糖等等——但至今那一袋都沒有動，我覺得如果可以把它放到過期的話，那就成功了。可能是因為知道自己有打針，那個慾望沒有特別強烈。在習慣上面也去做調整，覺得這東西有點像是心理上的 cue，在過去一兩禮拜也持續跑去運動。

最近找到一個新運動：打網球。網球教練含場地費大概 1700 到 1800 塊，跟健身教練（1300 到 1400）相比，還蠻划算的。短短大概一個禮拜，已經可以跟教練很順暢的把球打來打去，維持五到六個回合左右，也是因為教練本身超強的關係，可以快速學習。

網球其實是個相對難的運動，沒有這麼好上手。你以為揮臂是最重要的，但後來發現腳步才是最重要的，跟學泰拳有點類似——最後都是 footwork 跟 legwork。打網球需要手跟腳跟眼睛的協調，例如說腳如果出 7 的話，手就出 3；腳只出 1 的話，手就要出 8 之類的，一開始是蠻挫折的。

那天教練說早上八點半有人 cancel，問要不要來上課。一般早上八點半我要看盤，可是我站在那邊尋思了一下，就跟他說好。這讓我突然發現很多可能性——原來我現在早上是可以去做別的事情的，原來我現在的壓力沒有像之前這麼大了。健康如果沒有顧好，對生活影響才是真的很大的。非常慶幸最近有這些發展。

## 市場分析：伊朗局勢與死貓跳

接下來進入市場話題。相信這兩天大家在迎接非常大的痛苦之後，出現了一個絕地大反彈，這個大反彈要拆開來講。臺股這邊是非常強勢，特別是回去踩了重要的均線之後又再一次彈上來，如果接下來幾個交易日持續唱高，那基本上就是一個 total 回檔的格局。

但如果用美股的角度來看的話，我只會覺得它是一個死貓跳。目前在美股的部位已經提早去降水位，所以會選擇開始去補一些東西。

自己臺股是不小心買得太滿，雖然這有一點凡爾賽的意味，但並不是故意講什麼——就是因為剛好手上的東西都有漲出去，一般只要有漲出去就會持續去加，波動放大的時候理論上部位要稍微扣一點現金回來，可是就貪心了，持續加加加加加。然後在禮拜一、禮拜二的時候，受到蠻大的重擊。昨天跟朋友分享持股，他們說「這些前面都還是強勢股，怎麼一天可以急轉直下？」。可是隔一天我今天大概吃了六個漲停。

就算是這樣，自己是不會直截了當說這個戰爭要停。因為第一，美軍部隊還是在那邊；第二，觀察油價，不只近月，連遠月的油價都還維持在一個相對高檔。雖然昨天伊朗官方有講說他們想要和談，但市場可能沒有完全相信。所以我覺得還是維持一開始的看法：只要油價維持在相對高檔，就要稍微小心一點。

以我自己的角度，稍微小心就是不去上槓桿。因為看到油價還在那樣的位置，加上看到 VIX 還是在高位震盪，我會擔心波動率可能會造成一些破壞。所以就選擇不用槓桿的方式處理部位，趁今天反彈的時候做一點點調節，去迎接後面的廉價。我們節目的長期觀點還是跟大家說：理論上你待在市場裡面越久都是越好，所以什麼春節廉價、清明廉價，理論上你都是要抱股票。

當然我們自己還是會做一些稍微激烈的操作，爆太多股票的話在接下來發生事情時，可能會出現一些情緒化的作為，所以還是會去把部位弄到自己舒服的狀態。

## 市場分析：NVIDIA 投資 Marvell 解析

最近大家應該有看到 NVIDIA 要投資 Marvell 兩個 B 的新聞，要針對 NVLink Fusion 做更多合作。先前情提要一下：在前面有看到朋友截圖一些討論區在講說「這是有內線才知道的」。我真的不知道，如果我知道這些超級 insider news，我就不是在做股票錄節目了。我們的資訊能力一定是比一般人好很多，但沒有好到可以知道什麼合併、收購這種程度。

我們只知道產業的一些發展，知道 roadmap 會長怎麼樣，可是很多時候就算你知道 roadmap，你不知道什麼時候會發酵。所以前面一直跟大家說我覺得它不會這麼快發酵，可是你看市場就漲上去，很多時候也不知道到底市場跟我們的認知要到什麼地方做交匯。

我自己壓住 Marvell 的理由：我知道它在 Google 做進去幾顆晶片，加上對它未來在交換機這邊的發展也是蠻樂觀的看待，因為這樣去做了投資。有點類似那時候看到茂達被陳泰明買下去一樣，代表 NVIDIA 也看到這樣的機會。雖然心中覺得最該去投資 Marvell 的應該是 AMD，AMD 缺這一塊，但最後是由 NVIDIA 先持股跑來做投資。

NVIDIA 其實買了蠻多東西，像什麼 Synopsys、CoreWeave、Coherent、Lumentum、Navitas，最近是兩個光通全包，加上 Marvell 全包。你硬要把它湊在一起，Synopsys 就是 EDA 設計，CoreWeave 跟 Navitas 可能就是 Data Center 部件跟 AI 工廠的擴張，Coherent 跟 Lumentum 不用講就是光相關的佈局，Marvell 是要拉進去 NVLink Fusion。

其實後來用一個最局外的角度去看的話，就會明白：他真的現金太多了，他就會去找東西買，就這麼簡單。盡量去買一些跟自己本業相關的東西，我們可以大概猜解他要幹嘛，可是很多時候就是錢多，他要找地方放，類似這樣。

從戰略佈局的角度，目前在 Hyperscaler 看到的情形就是：沒有像外面講的這麼誇張地 de-NVIDIA，但是在分散配置、持續有去推進自己的 ASIC。兩年前講這個的時候還被人家吐槽說 ASIC 根本沒看到什麼東西，可是現在大家就看懂了。這些科技巨頭，他們還是會想要有自己的一些產品，所以它不是一個 de-NVIDIA 的話，但確實是隨著這些科技巨頭開始推自己的東西，NVIDIA 的解方就是——既然沒辦法賣 GPU/GPGPU，那你有沒有可能讓我在你的 Data Center 裡面還是分到一些餅乾？

NVIDIA 的解方就是 NVLink Fusion，這個 Chiplet 可以包在你的 XPU 裡面一起做封裝，它提供了 1.8 TPS 的雙向頻寬。此外在 Vera 的 CPU 方面，如果你只有 XPU，NVIDIA 可以提供 Arm-based 的 CPU solution，或者像 ConnectX 的 NIC、BlueField DPU、NVLink Interconnect、Spectrum 或 Quantum 的 Switch、光通解方，全都可以給你。

所以他能做的事情有點像是說：你要選 Marvell 或 MTK、L-Chip、Broadcom 做 XPU 設計 OK 都可以，但你其他東西都有我的產品線可以去做支援跟使用。我個人認為，他的劍指是 Broadcom，最主要是要去打 Broadcom，去拉這些快樂好朋友——像是 Marvell、L-Chip、MTK——各種 NVLink Fusion 的活動，幫你們整合在一起。財務投資只是一個插旗的意涵，他並沒有辦法真正獲得什麼控制權，只是拿出誠意，放一個錢金在那邊。

但就整個市場來看，我認為這是一個藍海，不是紅海。就算 Broadcom 被分走一大塊，整個餅也可以變得更大，還是比本來的餅大很多，還是會維持一個非常漂亮的成長性。

假設今天你是 Marvell 的股東，我覺得這個東西不太算是一個極大力度的利多，它比較偏向宣誓意味的東西。然後特別是像 Jim Cramer 又跟你講說他要 all in Marvell，所以我自己是覺得搞不好渣男這一次還是會傷大家的心。但反正 well see，再稍微觀察一下。

## 臺股：玻璃題材跟進度更新

目前在臺股，上集有跟大家聊到玻璃相關的題材，最後去找身邊的朋友都 check 了一下。市場的反應真的超級快，很多人動得很快。最後面的結論還是跟上集提到的一樣：它可能接下來一年半到兩年，才有機會開始去做放量；如果裝置是提早去做拉貨，那等到認定營收，也是要在可能半年以後之間。簡單來講，它是一個比較偏向未來的題材。

不過你回頭看 CPU，那時候根本看不到半個營收跟獲利的時候，就提早拉上去了，所以也不排除有可能往這個方向發展。

接下來美股這邊，因為現在只能把它視為是整個盤已經走空之後的反彈。反彈之後如果油價持續維持高檔，這個反彈沒有到非常強勁，開始走橫，然後接著有一些均線下來又把它打下去的話，那個打下去的瞬間，我還是會去期待說有可能再來一波大的。

但我不會空手等待，我都會用部位的可能六到八成去做調整。當稍微覺得危險的時候，就簡單降一點部位。這並不是要展示說「你看你可以閃掉一些崩」，不是，只是你總是會有新的東西賣。

## Q&A：NVLink Fusion 對 Astera Labs 的衝擊

第一位「馬桶上的五四三」：

> 我覺得雙子座的總統比雙子座的女人更難懂。請問主委，從小到大最難忘的美夢跟噩夢分別是什麼？另外想請教，NVIDIA 與 Marvell 結盟，有些人說是 Marvell 的 retimer 跟 Memory Pooling 的解方，會影響到 NVIDIA Fusion 的聯盟小弟 Astera Labs 的產品需求？但我理解是 Astera Labs 主攻 CSP 的混合資料中心，影響應該是有限。另外說到 Memory Pooling，是否會在記憶體這邊大放異彩？主委怎麼看這塊的實際衝擊跟未來定位？

這位兄弟一看就是非常專業的人士，我儘量回答。

首先先講說最難忘的美夢跟噩夢：噩夢，有一段時間會一直夢到我當兵跳傘的時候掉到水溝裡面。那時候教官跟我講說掉到水溝是有機會溺死的，結果第一次跳傘我就直接插到水溝裡面，全身都是臭泥坐上運兵車回去。當下真的很恐慌，趕快坐起來撐起來，後來才發現水溝並沒有很深。美夢的話，比較沒有什麼——不太會去不停地回味什麼很好的事情。

然後講說這個結盟是不是對 Astera Labs 的產品需求會造成問題。現在每個東西都會跑去打 Astera Labs 跟 Credo，大家覺得什麼都要踹這兩個一腳，因為這兩個前面是高速傳輸最夯的標的。我自己到現在還是有 Astera Labs 的持股，他們有點像說現在是落難中，所以什麼東西都可以拿來講它。

但實際上嚴格來說，他們並不是打在同一個賽道上面。如果你今天講說在 GPU 的 Inference KV Cache 不夠，需要去 CXL 擴充到 HBM 的記憶體，那這邊其實是兩個不同層級，他們都可以做一個共存：一個是 Marvell 的 Structera，另一個是 Astera Labs 的 Leo，一個是 Host Side，一個是 GPU Side，所以應該是不同層級之間可以做共生。

如果是在講 Memory Pooling Across VMs，那 Astera Labs 的 Leo 會是比較受惠的東西，Marvell 在這個環節是比較沒有看到什麼。如果是在 NVIDIA Fusion 的機架內記憶體一致性，那應該就是 Marvell 的 Structera，因為它目前是跟 NVIDIA 的生態系做繫結。如果是講更長期的 CXL 3.0 以上，上什麼 REC Scale Fabric 的話，大家都有份。

所以你的判斷大致上是 OK 的——主攻 CSP 的混合資料中心，影響有限。在過去一陣子，Astera Labs 就是一個仍然喊打的角色，市場現在就是要光通，跑去買光就真的很舒服，估值可以無限上修，反而是跟傳統傳輸相關的東西一直被壓縮。可是實際上，等到後來市場的環境去改變之後，市場的一些論述也會跟著去改變。就算光也去做配置，漲多的東西都可以去抵消那些目前表現比較不好的 underdog。

## Q&A：Charles — 周杰倫新專輯感想

下面一位「Charles Hsu Chen」：

## Q&A：Choco — 跟自己反向操作的勝率

> 最近這個袋鼠盤真的是殺人誅心，我昨天超級想一箭出清，覺得川普跟伊朗一定沒完沒了，但是自己越不舒服的時候反而是好買點，我一張都沒賣還加碼。請問是不是跟自己反著做勝率很高？

對，如果說你發現你很常烙賽的話，就試著跟自己反著做，但很難。因為你跟自己反著做，你會想要跟自己反反反著做，在人心上的掌握其實沒有這麼簡單。最簡單的一個方式，我還是會建議大家不管是用電腦或是把它寫下來，因為很多時候你的感覺會騙你，只能夠這樣說。

最近這個盤很難做，沒錯。像我自己在昨天的大殺盤裡，還是有去做一些減碼，跟 A 君去解釋說為什麼這些東西要減碼。你看它第一次掉下去拉起來這邊我沒有動，第二次給我軟我就要先砍一些——因為上面卡了 1000 多張，我不出一點的話，後面如果真的再往下一根怎麼辦？你考量到這個風險，不是你後面可以賺多少錢，是如果這邊就一直下去，你今年績效就爆掉了。

所以反而不是擔心說今年績效要網上賠更多，是擔心如果這邊就直接往下怎麼辦，你會不會掏一點東西，你根本就沒有錢加，要去質押，壓力就變很大。其實你不要去覺得決定要放在某一個點位上、好像要一拳操人，但其實部位是可以帶狀的——你昨天可能沒有賣，你今天賣一點，你明天可能又買一點，後天又賣一點，這都是有機會會發生的。特別是那個關鍵的點位可能是恐慌、或說波動超大的時候，你看到 VIX 都跳上去，一般 VIX 跳上去的時候你做越多決定，其實都是越受傷的。

整個投資的交易應該是一輩子的事情，它並不是說要在某個地方去拼一個生死，你只要可以悟到這件事情，你就會變得更加有彈性。
