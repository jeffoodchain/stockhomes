Mihong 這次回歸的 Maka 組合，邏輯很簡單：私立 Maka 膠囊就是日常打底，這是你的基本持股，95% 高純度、600% 濃縮，目標是要讓你每天的精神都維持在均線之上，不要讓體力出現斷層。極濃瑪卡粉包則是加強保養，就是你的槓桿工具——6770 毫克的頂規劑量，加上人參皂甘和 L-精胺酸，當你遇到高壓會議或必須硬撐的關鍵時刻，這一包讓你突破盤整、強勢續航。

這次一樣是老樣子，給股癌聽眾最簡單、最不用動腦的方式，不用輸入折扣碼，直接下單最高限省 1980 元，省下的時間跟錢拿去專注在更重要的事——愛你的瑪卡。

## 開場漫談：戒菸心得與深呼吸替代法

好，那我昨天看到一個很有趣的分享，在這邊跟大家討論一下，我覺得可能可以幫助一些想要戒菸的朋友。像我自己以前也是抽菸抽超大的，雖然我不算老煙槍，大概從高中抽到出社會的幾年，中間有斷斷續續想要戒菸幾次，但都失敗，大概最多一兩個月就會直接停掉。最主要的原因是只要跟朋友去唱K、或去吃熱炒，那樣的環境就會觸發你想要來一根的衝動。以前自己一天大概消耗兩包左右，最喜歡七星藍莓、黑七星，不然就是紅色 Marble，都是比較濃的菸。

抽到後來，自己也發現走樓梯會喘，早上起來一堆痰。所以抽菸這件事，除了身邊的人覺得你很臭、路人側目之外，對自己的身體其實也很不好，非常推薦大家勇敢去戒菸。

那我昨天看到的這個影片說，其實你要想抽菸這件事情——把抽菸本身給拉掉，它是一件很好的事情。什麼意思？你什麼時候會抽菸？早上醒來走到陽臺、從人多的派對跑到外面呼吸一下、吃熱炒吃飽了走出去、繁忙的會議結束覺得需要放鬆一下走出去——你仔細想想，這些時刻本身就是非常適合去深呼吸的時候。所以或許你喜歡的，部分是菸跟尼古丁，部分其實是深呼吸這件事情。

如果說你可以在繁忙的會議之後走到戶外深呼吸一下，在吃完熱炒超飽的時候走到戶外深呼吸一下，在派對裡已經快要 wear out、太多刺激的時候走到外面只有你一個人在那邊呼吸一下——你就會發現，其實你喜歡的不一定全然是尼古丁跟菸，而是那個呼吸的感覺。

我突然想通這件事情之後，就自己在過去幾天試看看，走到外面去深呼吸一下，突然發現腦袋變得很清楚、狀態變得很好。所以或許大家可以往這個方向去切入。如果有人早一點跟我講的話，那時候就不用瘋狂吃零食、每天咬口香糖、用尼古丁貼片或那種吸起來辣辣的東西了。

這個事情之所以讓人沉溺，很可能就是因為它本身結合了我們人類最原始的一個需求——你需要在很繁忙、壓力很大的時候，在人太多刺激過強的時候，走到外面，一個人或跟三五好友，大家不說話，稍微深呼吸一下。那一兩分鐘的深呼吸真的會改變很多事情。

總之分享就是希望大家可以有效地戒菸。煙跟酒都是比較不好的東西，能少就少。酒難免，特別是年紀大了身邊長輩朋友聚會時可能還是會喝，但我自己本身沒有飲酒習慣。倒是有注意到現在新一代年輕人（2000年以後出生的）蠻多是完全不喝酒的，甚至有些 party 是辦在麵包店裡，大家喝汽水或茶，不靠酒精也可以很酷。

我覺得新一代年輕人才是真正活出自我，不受那些社交習慣和禮儀的限制——什麼「請客菸」、什麼「一定要喝酒」，他們完全沒有在搞這套。特別是在 AI 時代，生產力本身越來越廉價，以前貴的職業現在搭配一些 Token fee 就可以產出很棒的效果，甚至大家開始討論 Universal Basic Income 的可能性。所以他們提早做這樣的準備，不對工作有執念，你要分他股份，他還是先問你「可以準時下班嗎？不行那我不要」，但這可能才是正確的生活態度。

稍微跟大家分享一下自己的心得。有些成癮的東西，像我電玩成癮，如果沒有電玩成癮很多時候不知道在生命之中還可以幹嘛——所以有些你喜歡的東西，偶爾吃美食、打電動，或還是喜歡抽個菸喝個酒，可能都還可以，只是要節制，不要讓它變成你的老闆，叫你做什麼就做什麼，那就比較不酷。

## 市場話題：美股多頭回溫、CPU 族群爆發

好，那接下來我們來進入市場的話題。大家最近應該還是有看到一些關於中東的各種有的沒有的東西，就像我們上集跟大家講的，一般看到那些大K出來之後，後面的一些訊息就會比較頓化一點。當然現在很明顯又再一次拉到一些壓力的位置，臺股這邊已經拉到新高非常到位，甚至是世界第一，已經是多頭沒有什麼任何的疑問。美股來到一些壓力的位置，雖然我們會直接把站到季線上面視為說現在又再次回到多頭行情，但後面可能就是有一些訊息再出來的話，有機會就會再往下打，如果下面都撐得住，那應該就沒有問題，有可能這一波的修正就當成結束了。

那同時呢，在過去一個禮拜，我自己算是過得非常開心，終於在美股今年第二季的帳上，終於有賺到錢的味道了。在第一季的時候，只有少數的時間待在水上，大多數時間都在水下。最主要的問題就是，早知道全部買光通就好，可是因為你手上不是全部都是光通——你有晶片、你有軟體、你有些有的沒有的、你有巨頭——他們可能在過去的表現就是沒有這麼好。所以在這段時間，即便手上有光通的部位噴得非常兇，可是因為有太多的拖油瓶，導致整體表現並不是這麼好。

但是在過去這一陣子，已經順利地回正，而且是快速往上爬，爬的速度讓我自己都嚇到。有時候就是說，選擇比努力重要。你在那些很垃圾的標的努力了半天，然後發現就算你可能抓了很好的買賣點，你還是無法避免地看著淨值不停往下掉。現在在資金規劃之下，把錢丟到像是 CPU，或者說 Marvell，或像最近的高速傳輸，其實也重新復活了；光通又在創新高，已經是非常有效地在資金調動之下持續攻新高，希望今年可以在美股做出非常好的表現。

## CPU 超需求：Amazon Graviton 連 CSP 自己都不夠用

那過去數集，我們都一直跟大家聊到 CPU 相關的議題。那一般在我們自己的做法就是，我們會有一個想法，然後拿真金白銀到市場裡面去做驗證，不是嘴炮，反正每次有什麼想法就是一定拿錢去做實驗，如果對的話就持續加碼。所以如果真的有咬到東西，其實都會在往上爬的這個階段爬得非常的快。

那最近 NVIDIA 他也去入股了一家叫 SiFive，他是在做 RISC-V 的一家公司。這個我算是有聽到身邊產業圈朋友跟我聊到，他說其實現在大家把目光放在 CPU 這邊，因為知道在 Agentic AI 時代，很多的工作除了 GPU 算力之外，你必須要靠 CPU 就像教練一樣去做排程，大量用到 CPU。那當然 RISC-V 這樣的架構也是有可能去做出那種特化版的 CPU，所以它有可能會重新被市場給關注。

然後在 Custom Made 的 ASIC 這邊，其實最近也開始獲得很多關注。像是在 Amazon 這邊，他們就有提到說有客戶想要跟他們全包下 Graviton 的 CPU 算力，但 Amazon 直接跟他說：不好意思，我們自己都不夠用。你要知道 AWS 是 CSP 裡面的 Power Player，他們有非常大的容量，所以 AWS 講了這句話，其實隱含的意思是：在未來的一小段時間，CPU 是非常缺乏的。

有兩家客戶去問說可不可以直接全包，他直接跟他說我們自己要用。這個意思就是說，要嘛 Amazon 會在後面加大 CPU 的各種晶片跟生產去供這些客戶——這個我覺得必然會發生；第二就是這些客戶因為沒有 CPU，就必須去找別人，甚至找一些像 GPGPU 這樣通用品的廠商，Intel、AMD 之類的，他們就是有機會在後面都會產出不錯的成績。

就是說在這個股東信裡面，已經像是洩題了，就是告訴你說 CPU 非常好。所以在我自己的角度，會認為說持續看下去，手上的 CPU 股票就持續拿好，甚至開始去思考說有沒有可能走出除了 2B 很好之外，然後影響到 2C——類似我們在之前一些電話會議裡面已經有看到，像 Intel 就有提到說他們是為了要做 2B 的東西，而會去排擠到 2C 的東西，甚至是刻意為之。那反而 2C 也可能因為這樣子產出一些機會，就是在大家都一面倒不看好、認為說以今年來看手機或 PC 都會很差的時候，有沒有可能在這邊也會另外產出機會？

但我覺得最保守的做法，當然還是先鎖定 Server 端的 CPU 或者說 Custom Made 的 CPU，如果有一些額外機會產生的話，當然可以往消費端的角度也看看。

## Anthropic Mythos：算力不夠才是沒發布的真相

那最近在 Cloud 這邊，Anthropic 他們推出了 Mythos，它並沒有對外開放，只先開放給一些策略夥伴，他們的用詞是因為這東西太強大了所以我們不能公佈。老實講，這個我有點想要吐槽。但我們知道說以目前的模型來講，Anthropic 毋庸置疑是最猛的，特別是在 2B 的應用，它是 dominant 的地位。

但其實這些 AI 模型 provider，很多時候都會不停地……我覺得是這樣子，因為他們有很龐大的壓力——就像他們的老闆自己也曾提到，如果成長性慢下來，說自己會破產，因為花太多錢投入算力。所以他們必須維持一個非常漂亮的成長率。為了這個成長率，有時候我覺得他們會講出很聳動的話。

像 Sam Altman，他一開始出來講話的時候我們還會認真聽，可是後來大家應該有注意到，我的節目就有點轉向，就是說我不太喜歡這個人，我覺得他講話有點過度尬吹。那現在我慢慢覺得這個 Dario Amodei 也是有一樣的味道出來，就是整天說我們的東西太危險了、可能會影響到什麼、美國政府可能要跟我籤什麼才可以使用我的東西。我知道你的東西真的好用真的強，因為我們自己也是第一線在使用 AI 產品的人，但有時候那個尬吹的成分就高了。

像他們對外公佈說，他們懷疑他們的 AI 現在自己有一些想法，因為它可能會自己去生成一些故事性內容的東西——不是啊，它就叫做 LLM，它本來的工作就是去生成這些東西。可是我覺得他們有點那種 delusional，說這代表要產生一些智慧或什麼的。

那聽到這邊，一些新的聽眾可能就覺得說這個傢伙是 AI 黑嗎？不是，其實我們是 AI 狂粉，但很多時候我們想要去踩一些煞車。特別是像每次 Anthropic 出來推東西，就會導致市場裡面的腥風血雨——市場裡面的泛軟體股，像 Cloudflare、Palantir、CrowdStrike，他們都曾經爬到近軸附近，就等於說今年沒有跌，可是像這一波他們釋出新產品，然後再一次的把這些東西再倒下去徹底一次，我就覺得蠻靠北的。因為我自己也是長期持有這些標的，所以就會覺得市場的 FUD 情緒已經讓我自己覺得有點煩躁。

任何理性的人都知道，之所以他現在沒有辦法把 Mythos 放出來的原因，是因為他的算力不夠。簡單講就是算力不夠。這個東西放出來的話，大家一定會把他罵爆——為什麼？因為現在大家已經知道說，像你去使用 Anthropic 的東西，它在某些時段（特別是美國人起床的時段）你會注意到你的 AI 變笨了，因為太多人在使用，算力是不夠的。

這也是過去我們提到說，像 Google 或者說其他 AI 競爭者，他們時不時會出現的問題——當太多人去使用它，它一開始很強，但太多人用就會變笨。所以如果今天他推出 Mythos 用到更多算力，那一定會讓大家感覺到這個東西並沒有像他講的這麼聰明，他只有在少部分的人去使用的時候才是比較強的狀態。

所以這東西其實也不是只有 Mythos 如此，包含他前面的一些產品也是一樣。至於什麼時候可以解決這樣的問題？就是算力的供應失衡必須要快速去解決，才有辦法去解決這件事情。可是目前是沒有辦法快速的，特別是當大家發現說 GPU 或者說 Accelerator 的 ASIC 目前已經相對穩健，可是又再一次跑出來 CPU，這個是很難以估計說到底需求有多少的東西。

所以嚴格上來說，這些軍火業者——像是可能 TSMC，或者說後端的封裝，什麼 Amkor、SPIL 或是相關的先進製程要用到的各種東西——應該都還可以再好一陣子，因為以目前來看大家本來講說 GPU 或是 ASIC，可是現在你們還要再多看一個 CPU，等到 CPU 可能都完美地做了解決之後，說不定又有新的 AI 模型要用到更多的元件。所以目前看起來這個需求還是有點像無底洞的狀態。

那我認為 Mythos 沒有辦法對外推出，並不是像他們說的那樣可能會被人家拿去攻擊或怎樣，而更大的原因是算力限制。像這樣去尬吹自己東西有多厲害，這不是只有他會這樣做，每家都會這樣做。你其實去看 2019 年的時候，OpenAI 就出來講說他的東西有多厲害、會有多恐怖，可是已經是 2026 年，我們的世界還是沒有毀滅。

所以接下來關注的重點就是，等到 Mythos 推出來，那可能就代表說他已經 secure 到夠多的算力，他就會把它放出來，並不是大家講的可能這個東西真的有多恐怖多嚇人這樣。

至於那些殺下去的軟體股會怎麼樣，我個人是認為因為那算是我的長期持股，所以我自己會繼續抱著，可能等到下一波他們開始要進攻的時候，我們才會再去額外做注意。不然這陣子我覺得我自己也蠻意外說，Anthropic 這樣的 AI Doomsday Call，每次都去把這些 SaaS 或者說相關的軟體應用跟整合商打下去。我以為早就該告一個段落，但還是持續在發生中。

## 被動元件：Lead Time 往上拉，禮拜三法說會是重點

最近在臺股也有兩件蠻有趣的事情。首先快速聊一下被動元件。被動元件我們算是可能在兩三個月前就持續有去注意，可是我自己覺得那時候買太早，所以認輸之後後來又有再回頭去做介入，現在就在思考說要不要把這個部位放到很大。那下個禮拜會有一個比較重大的事件，就禮拜三國際要開法說會。

沒有意外的話，法說會的內容應該是會全面性正面。為什麼？因為我們現在已經有注意到說很多的被動元件都開始出現 Lead Time 是往上拉的狀態。它還沒有像記憶體這樣全面缺貨，可是已經在像是 Tantalum 電容、SPCap、鋁電容上面已經有注意到是嚴重缺貨。MLCC 已經在警戒線附近，MLCC 目前在市場裡面最缺的應該是比較偏向像是春田或像是三星電機所做出來的比較高階 AI 應用的。

這有點類似 2017 年的狀態，那時候也是可能在一支手機或一個電動車裡面要用到超多的被動元件，導致一些高階廠商往高階方向走，一些比較低階的產品就放出來。它其實有點類似的邏輯，就是有一個主軸產品，以前可能是手機或電動車，現在就是 AI 伺服器，所以有機會就是會變成是一波新的缺貨潮。

那我自己有在臉書分享這個文章，很多時候我們都是拋磚引玉，故意丟出來看大家怎麼講。那有一些產業的朋友就有來給我 feedback，基本上在產業的朋友都有看到這樣的一個趨勢，只是他們的說法就是說，這有點類似說二三或二四的記憶體，就是你不知道什麼時候它會發作。那時候發作的原因是因為 Sora，整個觸動到記憶體族群噴出去，還有那時候有看到 SanDisk 的一個漲價信，我們在第一時間就有跟大家分享。

所以可能就是當然漲價性我們過去在被動元件圈已經看到很多了，它可能需要某一個事件去做催化跟驅動。所以如果說有那個事件跑出來的話，那可能資金就會往這個方向去看。那接下來可能就注意一下禮拜三國際的法說會講什麼東西，沒有任何意外的話，就是我們已經看到說它下個 Q 也是要持續漲價，然後再來就是它旗下的 KEMET（基美）也是持續在 Tantalum 電容上面去做漲價。所以被動元件圈非常缺，這應該是沒有什麼太多的爭議，到後面還會再更缺。

## 光通打件廠：東方有貴人，SMT 閒置廠成新寵

那接下來另外一個蠻有趣的題材，在這邊跟大家分享一下。總之就是現在有蠻多的光通廠，不管是美系的（其實有些是美系，可是它是臺股，就是身體裡面是臺股的），再來或者說臺灣自己的一些光通相關元件廠，我們最近有注意到一個趨勢，相信股票圈的人士應該大家都有發現。

我覺得說像前面大家買的先鋒是怎樣——就是去幫人家做代工 Shuffle Box；那後來大家跑去買了一個網通廠，因為那個網通廠有 SMT 產線；然後在過去一陣子，大家跑去買一些 LED 的打件廠。為什麼跑去買那個 LED 打件廠？因為就在講說，美系的這些客人們，他們現在就是需要這些產線。所以他可能就是自己去自帶這些裝置進來，那裝置應該也是甲方去付的——就是可能這些巨頭，他們需要這些光通相關的元件，所以他就付錢給這個廠商買了裝置之後，然後這個廠商可能再去找另外一個有場地有產線的廠商，把裝置放進去去做生產。

像這樣子的標的在臺股是越來越多，現在已經是上升到大概有四檔是這樣。所以我開始不免地認為說，這會不會有機會變成是某一種新的趨勢？首先大家先知道 SMT 打件廠，把一些電子元件弄到板子上面，其實毛利本身並不是一個太高的東西，可是過去可能有蠻多的閒置。像有些在做 LED 的，它 SMT 的打件其實是非常完善的，只是說產線可能沒有辦法放滿。所以在過去大家都不會喜歡它，誰會喜歡這種沒有在題材上的東西？

可是近期發生的事情就是，因為可能光通的需求真的是太大了，所以他們必須要去把很多的產能生出來。因為自己可能去蓋廠，又需要過環評、土地取得不易、買廠房可能也沒這麼簡單，有一個可能相對簡單的做法是：我直接去找既有的廠商，他即便跟我的本業根本就是沒有關係，反正沒有關係，你就是給我你的廠地跟人力就好，可能裝置或相關 know-how 我自己會進去幫你去做處理。

那像這樣的標的在臺股算是越來越多了，所以這有可能會是接下來的一個新的趨勢。但是我自己稍微跟朋友討論了一下，這個你很難提早去佈局。就舉例來說，你現在可不可以去找一些有 SMT 產能、然後你知道它的產線稼動率並沒有很高，你就先去買然後問說會不會有客人來找它？這個可能在投報上面就沒有這麼好。所以我們的做法就是說，把這些股票全部撈出來，然後接著去做一些調查，如果有辦法調查到的話最好；如果沒有辦法調查到，誰轉強誰就是可能有一些新的故事在背後。

只是這個可能被我們排在介入順序的 Tier 會比較後面，因為它有點像是在賭博。可是我們自己已經有看到的廠商是有四家，就是有四家廠商他們的狀態是反正因為光通這些客人的需求太大，所以就把裝置或有的沒有的東西委託你在你這邊去做生產。分到的錢雖然不多，可是對這些廠商來講，他可能現在是一個虧損的狀態，所以不無小補，毛利即便可能就 10% 上下或甚至更低，可是就是賺錢的東西，而且可能來的量是很大的。

所以這可能也是在後面可以稍微注意的一些新話題。我相信這個後面市場就會有一些什麼新聞，因為這個太誇張了——就我們也沒有想過說，怎麼會這麼多人會來找這些八竿子打不著的廠商。當然我們講說光通某個程度上也是一種泛網通的題材，可是一個是做那種 CPE 小東西的廠商，你怎麼可能會去做共同的東西？要後來知道說，原來是因為東方有貴人來了，貴人要他們去拓產先弄東西，就導致說原來現在可以有這麼多的訂單憑空生出來。這個可能是說你投資這家公司的時候根本就不知道。

當然這個其實我覺得它可以視為是一個可能深水區的東西，就一般人比較不輕易去介入，因為它可以把東西給你，當然它也可以把東西抽走，或者說可能還在建廠或驗證的階段，然後最後面沒有給你，可是股價是炒到恨天高，那後來就會崩下來。所以還是要小心。但我們還是會把自己有注意到的一些機會都跟大家分享跟討論一下。大概是這樣，那這節目先聊到這邊，我們接下來進入問答的部分。
