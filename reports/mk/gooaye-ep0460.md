## DaVinci Agent 核心架構

那這個展最主要我們就要去看達哥。我並不知道去看發哥什麼 IoT、什麼 Dimensity 9300 什麼的，這些東西對我們來講就是我們已經是有掌握到或是已經知道的東西。那達哥對我們來講是一個比較陌生的東西。

那達哥雖然我們在節目可能好幾個月前有跟大家聊到有這樣的一個東西，就是說聯發科他裡面有串一個 OpenAI 的 API，然後他們有搞出一個東西叫做達哥。當時我對達哥的認知就是說他是一個 LLM，然後他可以幫助你去不然說 coding 或者說問問題，都可以透過達哥去做解決。然後上一次聊達哥的時候是提到說他們內部是有去針對 embedding 的部分做加強，然後做出了 RAG。

其實 RAG 就是有點像說你把一些 data feed 給他，這個 data 可能是說公司內部的資料，所以讓他去減少一些幻覺的問題，還有說或是知識沒有跟上，以及亂回答的問題。他可以回答得更加的精準。那套一句發哥 David 跟我講的話，他說這個就是像是 open book，RAG 就是 open book，就是開答案給你看。

那另外一種 embedding，他也比較像是說從頭開始壓壓學語，然後你重新的去學某一種專門的記憶。反而不管是 RAG 或是 embedding，他都是去幫助這個 LLM 模型可以回答的更加的精準的一種技術。

達哥他其實不只是一個 Large Language Model，他不只是像我本來認知的就是說你去串了某個 Model 的 API，然後你把它放在自己的公司以自己公司的資料去 Find Tuning Embedding，然後讓它變得更加的精準。他不只是這樣一個東西，他其實已經變成是 Agent，他們把它稱為是 Agent，就是某一種助理。這個助理真的是厲害，他為我展示了一些我覺得非常強大的功能。

## 訂票 Demo

像有一個就是他直接訂票，而且他訂票不是說什麼 Demo 給你看，說我們想象一下我們家怎麼樣做，你看他未來可以幫你訂票。他直接幫我訂票，他直接用他的 agent，然後我輸入我的一些資訊給他，然後幫他做我的身份證字號、我的電話、我想要有什麼樣的一個行程。我要從臺北到高雄的蓮池潭，我幾點要出發，我明天幾點要回來，我直接收到定位確認的一個簡訊。所以他是真的就 work 了。

那當然我可能不太方便就講說他是透過什麼方式或者說他實際上是訂了什麼東西的票。但反正總之這個東西就真的可以達到這樣的一個效果，所以光是可以去直接執行你的指令，他就讓他跟其他的 Large Language Model 拉出了很大的一個距離。

那實際上他的作用機制是長這樣子。發哥的達哥呢他是一個 agent，然後這個 agent 呢你就想象成他是一個數位的助理，然後這個助理他背後有很多的 model 去支援他。包含像是 Claude、像是 GPT、像是 Gemini、這些大家非常熟悉的，像是 Mistral、這些 model，他都融合在達哥的架構下面。然後透過 Prompt Engine 去把你給出來的指令到這個 model 裡面去算一算之後，然後他給你一個 feedback。

這個 feedback 一般我們在 LLM 上面看到就是說我可能問你一個問題，你給我個答案，或者說我給你一個指示，然後你給我一個就是我想要的回應。但是他不只是把這個回應交給你，他同時他還透過了 plugins，就是所謂的外掛，去達到像我請你幫我訂票。

那我今天如果是去問 ChatGPT 的話，我說我要去高雄蓮池潭，然後我想要今天出發明天什麼時間你要回來，然後他可能對可以去幫你查一下行程表，告訴你可以怎麼樣做。但達哥呢他是可以直接幫你執行，也就是說你真的可以變成甩手掌櫃，就是你直接透過語音的方式跟他講，你甚至不用打字就說我要去做這樣的一個事情，我要去訂這樣的一個票，請你幫我做，Telegram 做了。

## Smart Home Demo

那再來第二個 Demo 是 Smart Home，那 Smart Home 的概念其實已經出現了蠻久了，那我相信一下大家對於所謂的智慧家庭的認知就是有一個智慧音箱，然後或者說今天家裡可能有一臺 iPad。像我岳母家是這樣子，就是你有一個 iPad，然後這 iPad 可以控制你的窗簾、燈光的明亮、音響，就所有東西都是連在上面。那這就是我們現在認知的所謂的智慧的家庭或者說 IoT 物聯網。

但實際上他們所展示的東西，我覺得是 step up，就是更進一步的東西。一樣是把大家前面的達哥，你可以想象成他就是 Jarvis，他就是鋼鐵人的助手，然後整合進去你的智慧家庭。所以像我們之前有一集有跟大家聊到小米的人車家，我覺得小米就是這樣的一個 TA，他就是可能達哥的某種受眾或者說其他的中國品牌或者說美國品牌都有可能。

就如果說你今天的 solution 是包含了除了手機之外，也有家電，也有汽車的話，可能就可以直接把達哥這一套系統直接整合進去。在你開車回家的路上，應該說你上車之前，他可能就先把你冷氣開啟了。那你開車回家，剛到家可能車庫燈就開啟，然後告訴你說今天是不是老樣子，老樣子怎麼樣？就是可能冷氣先幫你開，家裡的燈光先幫你開，電視幫你開啟來。

他還是會經過你的同意，就是他們在設計這個 agent 的時候，他是希望說這個 agent 他雖然記得你要什麼，他也知道你要什麼，因為他裡面有一個 DaVinci Memory，就是他把你的一些 pattern 給記起來。可是同時他不會過度的去干涉你的生活，也就是說不管他要做什麼事情，他還是要先問過你。但是他不會傻傻的像我們現在認知的一些所謂的物聯網或說智慧家庭的東西是，我要去 cue 這個音響，然後剛剛講說放歌他才會放歌。他已經知道說你回來就是要聽歌，所以他直接問你說要不要把你放歌，他多了一個這種主動詢問的事情。

所以看起來我覺得還挺酷的。當然他的 demo 可能做的比較陽春一點，就是他做一個很可愛的小房子，然後小房子上面插了很多晶片，那可能透過亮燈、暗燈或是說 LED 閃爍的方式來告訴你說你看這些東西是實際有在執行的。雖然看起來很陽春，但是我知道說如果它放進去某個系統廠裡面，那它確實就是可以直接變成一個可以 work 的 solution，所以這個看下來也是還蠻有趣的。

## Agent 與 LLM 的差異

所以你下次來跟大家炫耀說你賺錢是嗎？還是說你是套在可能更高的山上，然後現在要跑出來問一下到底該怎麼樣做。不管是哪一種啦，我都覺得就不要問我這種小型的標的，因為我是不太喜歡回答小型的標的。就連我自己的小矽谷，我從來也不跟大家講說我買了什麼東西，然後滷鼠加針叫你趕快買。

我知道很多人做這種事，我不做這種事。所以我對自己的自我要求蠻高的，就是我不希望去影響到市場。所以也不要來問我這種小型的東西。那其實我知道有蠻多在 QA 來問我這種小型東西的人是充滿惡意啦，他是故意的。因為他想要有一點聲勢啊，然後要有一點流量啊，所以就故意跑來問我。然後跑來問我之後呢好像我有一次被問了某一支東西，然後回答，又馬上把我回答的東西轉去 PTT。

真的很多這種幹很噁心的人，所以我不知道來者是善是惡啦。然後我也很反感這種就是想要去算計你或者想要去槓桿你聽眾的行為。那所以最好的做法就是我不要去回答這種小型的標題。不要跑來再問我這種東西。下次我看到這種東西我可能會選擇直接跳過。

如果說你問的是一些大公司或什麼的，我覺得那當然沒有什麼我不談的。只是一些那種很小型的公司，你就知道說你來問我怎麼可能會知道。你當我他媽百科全書，你當我是維基。我們臉上是有寫 wiki 是不是？就不知道，你跑來問我要幹嘛。然後你自己買的東西，你都不知道，你還問人家是要買是要出？你不賠死是要賠死？

主要去想一下這件事情。這個市場的每件事都要有人買單的，你不賠還有天理，所以真的要小心。
