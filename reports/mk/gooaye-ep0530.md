## 臺股軟體股的轉折點

臺股呢，因為可能轉軟體的時間是比較慢一點。我說市場就是市場去了解到軟體它的一個潛在爆發力的時間是比較慢。那在這個禮拜呢，才開始很明顯的看到臺股的資金去往軟體的方向走。就是現在已經開始是非常明顯，是那種全面周全性都啟動了。

所以終於在臺股這邊軟體相關的佈局也獲得了很好的一個表現。那不然其實我之所以會在 12 月中去創一個 all time high，然後接著到這禮拜五才再創一個新高的主因，是因為我裡面軟體股是佔我臺股的大概兩成左右。所以就會變成因為有一個蠻大的部位是在前面有遇到修正的回檔，所以就卡了一段時間。

那很幸運的，雖然我的軟體股還沒有破它自己本身的新高，但是搭配其他股票的表現，終於是讓自己在臺股的績效也來到了 old time high。所以今天整天心情都是非常非常的好，從昨天好到現在。

## NVIDIA 5090 與液態金屬散熱

那昨天呢也收到了這個來自於 NVIDIA 的 5090。那這個 5090 是一張非常非常屌炮的顯示卡，價格也是要價不菲。那再來現在要拿到也是比較困難。那我是屬於非常幸運，可以拿到老黃的簽名版本。

那這張卡本來是打算要拿來用，可是因為那個簽名真的籤得太漂亮了，所以就決定把它供在架上，再買一張拿來用。一張拿來擺，一張拿來用。

那這張顯示卡它比較特別的地方是它在它的這個 chipset 上面是有一個液態金屬層。那這個液態金屬，其實我這很好奇，就是會不會後面變成市場上的一個話題之一。因為就我理解，他們可能會先用在 Consumer 這一邊，那在 Consumer 這邊去做一定程度的測試之後，他有可能會把它用進去 Data Center。那這中間可能不知道時間會拉多久，一兩年或是兩三年。但總之就是在 Consumer 這邊，我們接下來等到產品正式的大放量之後，越來越多消費者拿到 5090 之後，我們再來觀察大家的一個意見。

因為有時候只看自己的意見是不準的，要看一下整體市場怎麼樣回饋這件事。它的散熱效能是不是表現得比較好，它是不是可能會比較安靜之類的。

那其實像我自己本身，我最希望改善的一個問題，其實是現在的電腦主機太吵這一件事情。電腦主機因為隨著不管像是顯示卡，當然顯示卡是一個主要的大宗耗能的來源，但其他的裝置其實也是慢慢的在增強。所以導致呢，其實現在的風扇都越來越多，那再來就是那個瓦數也越來越大。

所以其實我覺得現在的主機是太吵了。那我相信可能等到一兩代以後，搞不好什麼 7090 之類的，到時候呢那個主機應該是吵到一個靠北。所以沒有辦法，就是可能要找到一些新的方法去做散熱。

那除了去改這個就是中介層的散熱之外呢，看有沒有辦法。我最近是有在研究啊，就上次有跟大家分享過，我有去找一些在海外組電腦的公司。他們有做一些是直接把整臺主機呢類似都用銅去做，所以就變成整臺主機是被動式散熱啊。只是它可以解的熱一般沒有辦法到那 500 瓦以上，大概 300 多瓦就了不起啊。

所以你最多就像說你可以用到什麼 4070，他們是已經有一個一個整機的 solution。就是你買回來呢那臺機子上面是沒有任何風扇的，所以就不會吵，就完全沒有聲音。這個是我夢寐以求的一個機子啊。

但是因為我都習慣直上，然後現在直上的機子呢就特別是，只要是 90 系列，像 4090 或者說 5090 呢，其實都是沒有辦法去解那個熱。我希望有時候讓他們可以解決這個問題啊。

那所以呢，液態金屬這個話題，我覺得在後面可能會變得蠻有趣的。那在臺股跟美股呢，其實都可以找到相關的東西那樣。因為這個我們節目是不喜歡直接去喊一些標題，所以我們很多時候就丟一些想法給大家。大家可以自己去找看看，因為你只要稍微動動 Google 就可以馬上找到一些答案。當然要稍微比較一下，不是每個東西有稱到的就一定是。

那收到這個顯示卡非常高興，所以在這邊還是要感謝一下各方大德的協助，讓小弟可以提早拿到這樣子的一個酷東西。

所以 V3 呢，對於整個產業，其實是有蠻大的一個震撼。那這個呢，其實你去看一些 Earnings Code 就會注意到，就是很多家公司都有提到他們。

那我昨天在看 Net，也就是 Cloudflare 的一個 Earnings Code 裡面呢，他們就是有提到 DeepSeek 對他們的影響。也就是在之後呢相信在 Inference 端會大量的放量。因為呢他們很高興的表示說，終於不是隻有我們。他們本來就感覺只有我們認為說我們的 AI 模型可以更加的有效率。那現在呢有一個這個中國公司做。雖然當然他有一些他的疑慮，只是他提出來的兩個想法是正式可用的。

一個就是當然已經有前人之上的 MOE，那這個 MOE 他們玩出了新的滋味。再來就是 MLA，這比較偏向他們自己的努力。反正總之就是跟大家證明說，我可以用便宜的價格去做 AI。

那這樣的一個啟發，其實當然有些人可能不喜歡中國公司。但我在之前跟大家聊 DeepSeek 的時候聊過說不重要，你不喜歡它不重要。因為後面就是有其他公司一樣會站在 DeepSeek 開發的一個基礎上，然後去做出就是往更便宜的方向去前進的一個東西。

所以結論就是，就是整個 AI 模型在後面會更加加速的變成是 commodity，變成是一個大宗產品。這個也是符合我們自己之前的一個猜測。

## Cloudflare 與 Apple 的策略地位

那在 Cloudflare 的一個 earnings code 裡面，也是跟大家講到這樣子一個說法。也就是做模型後面可能會變成一個蠻艱難的生意，應該是會變得蠻困難的。

那像 Apple，我覺得就是站在一個很漂亮的制高點。因為 Apple Intelligence 它雖然現在是用 GPT，可是他們已經強調說他們是可以去接受使用其他模型的。所以是你們這些模型要拜託他用，說不定你們還要倒貼給他，就像是 Google 要去在 Safari 上面變成是預設引擎一樣，就必須要去付錢給他。

那在 Cloudflare 這邊呢，也是展示出了這樣的一個霸氣。他的意思是講說現在超多客戶呢都是在他們的 serverless 的 solution 上面去放這些 AI 模型。所以對他們來說，AI 模型多多益善。我可以選擇去部署各式各樣的模型讓我的客戶去做選擇。

我的客戶呢可以在上面直接去建立他的 agent。在電話會議上面就舉了非常多的例子，各式各樣的客戶在上面去做到了各式各樣的一個自動化。那所以對他來講呢，reasoning 跟 inference 的一個需求大爆發是非常有利於他們的。

所以他們也很高興的表示說，原來不是隻有他們一家公司。但這可能有點臭屁的成分，是有在關注要如何讓這些 AI 的 models 更加的 efficient，往這個方向去前進。他們相信這會是一個大趨勢。也是我完全認同，完全相信這一套。

那我相信這就是為什麼市場的一些資金開始往 IPC 跑的一個主因。

## IPC 與 Edge Computing 的深入分析

那當然我們過去聊過數次，那現在快速的 recap 一下。為什麼這些 IPC 有機會會吃到這方面的訂單？首先要先定義一下工業電腦是什麼。

工業電腦其實你可以想象成就是比一般居家電腦再高階一點的電腦。那這些電腦他們有時候用在一些比較極端的環境，像是一些軌道運輸的情境，就是可能放在軌道旁邊的某個這個鐵盒裡面，所以它會高溫日曬。那它就是要有比較好的一個耐用性。

那它有可能是放在醫院、診所、律師事務所或者一些辦公場合。那在一些什麼礦場之類的，反正總之他們一般會是需要去透過比較嚴苛的考驗，那要有很好的一個耐用性。

那工業電腦其實是一個非常廣的族群。像一般我們在講說 POS 機，那也是一種工業電腦。那只是我們在講這些 server 工業電腦廠他們本身也是有做，那只是一般他們做的東西不會是大家看到的那種主流的，像是之前的什麼 A100、H100 或是 B100。

要去開發這個東西是要拿到許可的，所以他們不會第一時間就有機會去做這樣的東西。這是前面那些大型的代工廠才有的生意。他們做的東西可能就要說是這個 NVIDIA 的 L40s，類似這樣子的東西。那一些比較就是偏中階或者說中低階的一個 AI 的 server，這是他們在專注的東西。

## OEM、ODM 與 IPC 的區隔

那在另外一方面就是像以前為什麼會有這樣子大型的代工廠跟工業電腦廠會分庭抗禮呢？最主要原因是因為當你今天去下單，如果你自己是買個幾百幾千臺的話，你就是直接找這些大型的代工廠。但如果說你要買的東西是就你一個辦公室，你搞不好只要用到五臺之類的。那你去找這些大型代工廠，他們可能不願意幫你開案，他們可能不願意賣你。

所以你就去找到這些工業電腦廠，然後讓他去幫你開這種小量多樣化的東西。那因為他是特地幫你開案，然後要去符合你的需求，所以一般來說他們的毛利數字會比就是大家所認知到的 OEM 跟 ODM 都來得高。他的毛利是比較好的。

那很多這些 OEM、ODM 他們本身自己也有去養一些工業電腦廠，有去投資或甚至直接把它買下來。所以就是我全都要的意思。但是其實是各司其職，有些是負責大量的，有些東西是負責小量多樣化的。那因為小量多樣化的關係，價格一般也就比較漂亮。

## Edge Computing 的定義與潛力

那我覺得我應該更嚴格的去定義這件事情。就是我認為其實在現在 Edge Computing 這個話題，Edge Computing 其實非常廣，像你的手機也是一個 Edge Computing。之後我們要講的 Edge 是講說在可能醫院、診所、辦公室、律師事務所、會計師事務所，他們的機房裡面，然後去放一個 AI 伺服器。

這樣的劇本有可能會更加快速的實現，比大家想的更早。最主要原因就是因為 AI 模型的一個大幅降價，然後外加開始更多人往這個方向去做開發，於是去部署自己的 AI 伺服器開始變成是一個有誘因的事情。

為什麼？因為當然大家會想說你東西直接上雲就好，可是問題是有很多東西是不能上雲的。那是有機密的或是有病患的隱私、你客戶的隱私、被告的隱私或什麼的。那這些東西你是沒有辦法直接讓它跑到雲端。

所以如果說你還是需要去槓桿一些 AI 的努力的話，你可能去找一個開源的模型，然後直接放在你們的機房。那這樣東西就是留在自己的地端，就不需要上雲。這個東西是有誘因的。

可是要瞭解到的是，因為現在等於說是開始去往 Edge Computing、往 Reasoning、往 Inference 去靠。但是不代表最後的贏家一定是這些 IPC。就 IPC 只是一個很容易想見的答案，但是不代表它是唯一的一個答案。

## IPC 的主要競爭對手

這些 IPC 他們最大的一個敵人是誰呢？就是 NVIDIA 之前推出來的那個 GB10。而且 NVIDIA 那個 GB10 可能不只是只有一代的機型，它說不定會再繼續往後推或是再往上拉一個規格之類的。那這些東西其實會直接變成是這些 IPC 的一個競品。

當然你會講說裡面用的東西不太一樣，但總之這些東西也可以放在你的學校、單位、辦公室、你的醫院、診所，還是那些地方。然後你要把模型部署進去，完全可以辦到。而且 NVIDIA 給一個非常有競爭力的價格就是 10 萬塊。然後裡面給好給滿 RAM。那 RAM 給得越高在推論的表現就會越好。

所以這是一個非常非常好用的機子。就是你光是看它的 spec，你就知道說它有很多的應用機會。

## 消費級 GPU 也成為競爭者

所以我們可以從這邊瞭解到說，就是這些 IPC 它未必是直接受惠的一個物件。因為 NVIDIA 也開始去針對這些比較小量採用或者說是預算沒這麼高的客戶，然後去開發一個適合他的機種。
